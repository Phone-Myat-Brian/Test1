# Web-based Flight Simulator 2020

A high-quality, single-file 3D flight simulator that runs directly in your browser. Inspired by Microsoft Flight Simulator 2020.

## 🎮 Play Now

**[Click here to launch the Flight Simulator](https://Phone-Myat-Brian.github.io/Test1/)**

*(Note: It may take a few minutes for the site to become available after the first deployment completes in the "Actions" tab).*

## Features

- **Procedural Terrain**: Infinite 3D world with vertex-colored biomes (Sand, Grass, Rock, Snow).
- **Realistic Physics**: Aerodynamics including lift, drag, gravity, stall speeds, and banking turns.
- **Multiple Aircraft**:
  - **Cessna 172**: Stable, easy to fly.
  - **F-18 Jet**: High speed, swept wings, high maneuverability.
- **Dynamic Weather**: Toggleable rain system with volumetric-style fog (Press 'R').
- **Interactive HUD**: Displays Airspeed, Altitude, and Controls.
- **Camera Modes**: Chase, Cockpit, and Top-Down views (Press 'C').

## Controls

| Key | Action |
| :--- | :--- |
| **W / S** | Pitch Down / Up |
| **A / D** | Roll Left / Right |
| **Q / E** | Yaw (Rudder) |
| **Shift** | Throttle Up |
| **Ctrl** | Throttle Down |
| **C** | Change Camera |
| **1** | Select Cessna |
| **2** | Select Jet |
| **R** | Toggle Rain |

## Tech Stack

- **Three.js** (Rendering)
- **Simplex Noise** (Terrain Generation)
- **HTML5/CSS3** (UI)
